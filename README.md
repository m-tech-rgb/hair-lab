# It-Girl Hair Lab

Client-side beauty MVP — tap ROOTS / MIDS / ENDS on your hair photo, then your inspo shade.

- No AI
- No API keys
- Photos never leave your browser

## Live site

https://m-tech-rgb.github.io/hair-lab/

## Run locally

Open `index.html`, or:

```bash
python3 -m http.server 8080
```

## Optional share card

Place a `1200×630` image at `/og-card.jpg` for social previews.
